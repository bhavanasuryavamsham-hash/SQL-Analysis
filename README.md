# SQL Sales Analytics Project

## 📌 Project Overview

This project focuses on analyzing sales data using **MySQL and the ClassicModels database** to extract meaningful business insights. It explores customer purchasing behavior, sales and revenue trends, product performance, and employee assignments through practical SQL queries.

The project demonstrates how SQL can be used to transform relational data into useful insights that support data-driven business decisions.

## 🎯 Objectives

- Analyze customer purchasing behavior and order patterns.
- Identify top customers based on purchase value.
- Calculate yearly revenue and revenue growth.
- Evaluate product line performance and sales contribution.
- Analyze employee assignments and customer distribution.
- Apply advanced SQL techniques to solve business problems.

## 🛠️ Tools & Technologies

- **MySQL** – Querying and analyzing relational data.
- **MySQL Workbench** – Writing and executing SQL queries.
- **GitHub** – Project documentation and version control.

## 🧠 SQL Concepts Demonstrated

- JOINs (INNER JOIN and LEFT JOIN)
- GROUP BY and HAVING
- Aggregate Functions (SUM, COUNT, AVG)
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Ranking Functions (RANK and LAG)
- Sorting, filtering, and conditional analysis

## 📊 Analysis Performed

### 1. Customer Analysis
- Counted customers in each country.
- Calculated the number of orders placed by each customer.
- Identified the top five customers by total purchase value.
- Identified customers whose total purchases exceeded their credit limits.
- Found customers ordering products across multiple product lines.
- Identified customers contributing the highest percentage of total sales.

### 2. Sales & Revenue Analysis
- Calculated total revenue generated each year.
- Identified the order with the highest total value.
- Analyzed customer purchases across countries.
- Compared country-level revenue with average country revenue.
- Calculated year-over-year revenue growth using window functions.

### 3. Employee Analysis
- Analyzed employees managing customers across multiple countries.
- Counted customers assigned to each employee.
- Compared employee customer assignments.

### 4. Product Analysis
- Identified the product line generating the highest revenue.
- Found products that had never been ordered.
- Counted products belonging to each product line.
- Calculated total sales for each product line.

### 5. Advanced Analytics
- Ranked customers by total purchase value.
- Identified the top three customers in each country.
- Found the most valuable customer in each country using ranking functions.

## 💡 Key Business Applications

This project demonstrates how SQL analysis can help businesses:

- Understand customer purchasing patterns.
- Identify valuable customers and revenue contributors.
- Monitor sales trends and yearly performance.
- Evaluate product line profitability in terms of revenue contribution.
- Understand employee customer assignments.
- Support strategic planning through data-driven insights.

## 🚀 How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Set up the ClassicModels sample database.
3. Open MySQL Workbench and connect to your MySQL server.
4. Select the ClassicModels database.
5. Open the SQL script containing the project queries.
6. Execute the queries and review the results.
